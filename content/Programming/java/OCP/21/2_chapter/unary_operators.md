- Un operador unario es aquel que requiere exactamente un operando o variable para funcionar.

| Operator           | Examples  | Description                                                                                                                                 |
|--------------------|-----------|---------------------------------------------------------------------------------------------------------------------------------------------|
| Logical component  | !a        | invierte el valor lógico de un booleano                                                                                                     |
| Bitwise complement | ~b        | invierte todos los 0s y 1s de un numero, esto se refiere a la representación binaria de los números en memoria                              |
| Plus               | +c        | indica que el número es positivo, aunque por defectos e asume que un entero lo es, a menos que se acompañe con el operador unario nengativo |
| Negation or minus  | -d        | indica que un numero literal es negativo                                                                                                    |
| Increment          | ++e f++   | Incrementa un valor por 1                                                                                                                   |
| Decrement          | --f h--   | Decrementa un valor por 1                                                                                                                   |
| Cast               | (String)i | convierte un valor a un tipo especifico                                                                                                     |
