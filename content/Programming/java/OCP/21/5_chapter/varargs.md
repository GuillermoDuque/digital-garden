- Un método puede tener al menos un parámetro vararg
- Sí el método contiene un varargs, debe ser el último parámetro en la lista.
- Al llamar a un método con varargs, hay 2 formas
    - Pasarle un arreglo
    - Pasarle los parámetros separados por coma
- Si omites el parámetro varargs, java creará un arreglo con cero elementos por defecto.
- Se comportará como un arreglo dentro del método.
